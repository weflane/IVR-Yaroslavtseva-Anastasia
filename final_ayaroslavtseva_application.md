**[ НАЗВАНИЕ ПРОЕКТА ]**

“BookMatch”

**[ ПРОБЛЕМНОЕ ПОЛЕ ]**

Современный читатель сталкивается с некоторыми сложностями: при огромном выборе книг сложно быстро найти именно ту, которая соответствует текущему эмоциональному состоянию, интересам и целям чтения. Существующие сервисы (рекомендательные системы магазинов, литературные соцсети) предлагают подбор на основе жанра, популярности или похожих покупок, но игнорируют ключевой фактор выбора - настроение пользователя и контекст. Это приводит к потере времени, разочарованиям и снижению вовлеченности в чтение. 

**[ ЗАКАЗЧИК / ПОТЕНЦИАЛЬНАЯ АУДИТОРИЯ ]**

Программный продукт может заинтересовать широкую аудиторию, однако я выделю несколько групп пользователей, для которых существует свой тип пользования. К выделяемым группам относятся:
* Активные читатели - те, которые читают минимум 1-2 книги в месяц, тратят на выбор новой книги значимое время
* "Заблудившиеся" читатели - те, кто хотят читать, но не могут выбрать книгу, потому что ни советы, ни списки не подходят под его желания
* Участники книжных клубов
* Библиотекари, литературные блогеры, книжные магазины

**[ АППАРАТНЫЕ / ПРОГРАММНЫЕ ТРЕБОВАНИЯ ]** 

* Формат: Прогрессивное веб-приложение (PWA).
* Версия для браузера: Поддержка последних версий Chrome, Firefox, Safari, Edge.
* API для книг (поиск по тегам, добавление, получение)
* API для пользователей (регистрация, история, «прочитано»)
* Подбор книги — не дольше 3 секунд
* Выдержка 100 человек онлайн
* База на 1000 книг, резервные копии базы
* Контейнер Docker

**[ ФУНКЦИОНАЛЬНЫЕ ТРЕБОВАНИЯ ]**

Программный продукт будет предоставлять следующие возможности:

* Регистрация пользователя
* Адаптивный тест: Поэтапный опрос для определения настроения пользователя, желаемых темпа и длины книги. Интеллектуальная выдача: Формирование персональной подборки из 3-5 книг с обложками, краткими аннотациями и атмосферными тегами.
* Подбор книги без прохождения теста на основе истории прочитанных пользователем книг и их тегов.
* Альтернативная навигация по каталогу. Навигация по тегам: Просмотр всех книг, отфильтрованных по тегам, без прохождения теста.
* Карточка книги: Страница с полным описанием, тегами и «эмоциональной картой».
* Личный кабинет и история. История «книжных настроений»: Дневник всех пройденных тестов и полученных подборок с привязкой к дате. Управление библиотекой: Функция «Добавить в прочитанное» – такие книги исключаются из рекомендаций. Создание списка «Хочу прочитать».
* Функция "найти похожие" - в карточке книги пользователь может нажать кнопку «найти похожую книгу».
* Экспорт и сохранение результатов в .txt или в формате визуальной карточки книги с обложкой в виде изображения (.png).
* Возможность добавить комментарий к книге, который будет виден только самому пользователю

**[ ПОХОЖИЕ / АНАЛОГИЧНЫЕ ПРОДУКТЫ ]**

Анализ нескольких программных продуктов, которые максимально приближены к заданному функционалу, показал, что:

* LiveLib / Goodreads: Мощные социальные сети для читателей. Недостаток: рекомендации основаны на оценках сообщества или друзей, а не на сиюминутном настроении. Нет инструмента для подбора "по чувству".
* Книжные рекомендации от крупных магазинов (Читай-город, Литрес): Машинные рекомендации на основе покупок. Недостаток: коммерчески ориентированы, не учитывают эмоциональный контекст, предлагают в основном новинки.
