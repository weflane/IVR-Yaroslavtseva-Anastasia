### [ Сценарий 1 - Регистрация пользователя ]

1. Пользователь открывает главную страницу и нажимает кнопку «Войти / Регистрация».
2. Система открывает модальное окно с вкладками «Вход» и «Регистрация».
3. Пользователь переходит на вкладку «Регистрация».
4. Пользователь вводит адрес электронной почты в поле «Email».
5. Пользователь вводит пароль (не менее 6 символов) в поле «Пароль».
6. Пользователь нажимает кнопку «Зарегистрироваться».
7. Если поля не заполнены, система выводит сообщение «Заполните все поля».
8. Если email уже существует, система отображает «Пользователь с таким email уже зарегистрирован».
9. При успешной регистрации система автоматически авторизует пользователя и перенаправляет на главный экран.

### [ Сценарий 2 - Адаптивный тест настроения ]

1. Пользователь открывает главный экран и нажимает кнопку «Подобрать книгу».
2. Система отображает первый вопрос теста с вариантами настроений (визуальные дескрипторы: короткие тексты).
3. Пользователь выбирает подходящий вариант.
4. Система отображает второй вопрос о желаемом жанре книги («Детектив», «Фантастика», «Роман», «Классика»).
5. Пользователь выбирает вариант.
6. Система отображает третий вопрос о желаемом темпе чтения («Неспешный», «Средний», «Быстрый»).
7. Пользователь выбирает вариант.
8. Система отображает четвёртый вопрос о длине книги («Мало», «Средне», «Много»).
9. Система формирует персональную подборку из 3-5 книг.
10. Система отображает ленту с обложками и атмосферными тегами каждой книги.

### [ Сценарий 3 - Подбор книги на основе истории чтения ]

1. Авторизованный пользователь открывает главный экран.
2. Пользователь нажимает кнопку «Рекомендации для вас».
3. Система анализирует теги книг, которые пользователь отметил как «Прочитанное».
4. Система находит книги с похожими тегами, которые пользователь ещё не читал.
5. Система формирует подборку из 3-5 книг.
6. Система отображает ленту с обложками, аннотациями и тегами.
7. Если у пользователя нет прочитанных книг, система показывает сообщение «Пройдите тест или добавьте прочитанные книги».
8. Пользователь может обновить рекомендации нажатием кнопки «Обновить».

### [ Сценарий 4 - Альтернативная навигация по каталогу через теги ]

1. Пользователь открывает вкладку «Каталог».
2. Система отображает облако всех доступных тегов.
3. Пользователь нажимает на один тег.
4. Система показывает все книги, содержащие этот тег, в виде списка карточек.
5. Пользователь может добавить второй тег для уточнения фильтрации.
6. Система показывает книги, содержащие оба выбранных тега.
7. Пользователь нажимает кнопку «Сбросить фильтры».
8. Система очищает фильтры и снова показывает облако тегов.
9. Пользователь нажимает на любую книгу для перехода к карточке книги.

### [ Сценарий 5 - Карточка книги ]

1. Пользователь нажимает на любую карточку книги (в ленте, каталоге или списках).
2. Система открывает страницу книги.
3. Пользователь видит: обложку, название, автора, развёрнутую аннотацию, длину книги и темп.
4. Система отображает все теги книги в виде меток.
5. Пользователь может добавить книгу в «Прочитанное» или «Хочу прочитать» кнопками внизу страницы.
6. Пользователь нажимает кнопку «Назад».
7. Система возвращает пользователя на предыдущий экран.

### [ Сценарий 6 - Личный кабинет и история ]

1. Авторизованный пользователь открывает вкладку «Профиль».
2. Система отображает: email и три вкладки: "Прочитанное", "Вишлист", "История квизов".
3. Пользователь нажимает на раздел «История квизов».
4. Система показывает дневник всех пройденных тестов с датами и полученными подборками.
5. Пользователь нажимает на раздел «Прочитанное».
6. Система показывает список книг, отмеченных как прочитанные.
7. Пользователь нажимает на раздел «Хочу прочитать».
8. Система показывает список сохранённых книг.

### [ Сценарий 7 - Функция «Найти похожие» ]

1. Пользователь находится на карточке книги.
2. Пользователь нажимает кнопку «Найти похожие».
3. Система анализирует теги текущей книги.
4. Система ищет в базе другие книги с максимальным совпадением тегов.
5. Система формирует подборку из 3-5 похожих книг.
6. Система отображает ленту с результатами.
7. Пользователь может открыть карточку любой из предложенных книг.
8. Если похожие книги не найдены, система показывает сообщение «Похожих книг пока нет».
9. Пользователь нажимает «Назад» для возврата к исходной карточке.

### [ Сценарий 8 - Экспорт подборки ]

1. Пользователь находится на экране с результатами теста (лента из 3-5 книг).
2. Пользователь нажимает кнопку «Экспорт».
3. Система открывает модальное окно с выбором формата: «Текстовый список (.txt)» или «Визуальная карточка (.png)».
4. Пользователь выбирает «Текстовый список».
5. Система генерирует файл `.txt` со списком названий и авторов книг.
6. Система предлагает скачать файл.
7. Пользователь выбирает «Визуальную карточку».
8. Система генерирует изображение с обложками, названиями и авторами книг.
9. Пользователь скачивает изображение или делится им.

### [ Сценарий 9 - Личные комментарии к книге ]

1. Пользователь находится на карточке книги.
2. Пользователь нажимает кнопку «Добавить комментарий» или иконку заметки.
3. Система открывает текстовое поле для ввода комментария.
4. Пользователь вводит текст (до 500 символов).
5. Пользователь нажимает кнопку «Сохранить».
6. Система сохраняет комментарий в базе данных, привязывая к пользователю и книге.
7. Система отображает сохранённый комментарий под описанием книги.
8. Пользователь может нажать «Редактировать» для изменения комментария.
9. Пользователь может нажать «Удалить» для удаления комментария.
