# Отличия готового продукта от заявки и сценариев
| База данных: PostgreSQL или SQLite | MongoDB | Книга хранится одним документом со своими полями (теги, темп, оценки эмоций), схему легко менять по ходу работы, есть бесплатный облачный вариант (Atlas) |
| Вход и регистрация в модальном окне с вкладками | Отдельные страницы «Войти» и «Регистрация» | У каждой страницы свой адрес, кнопка «Назад» в браузере работает привычно, проще проверять и тестировать |
| Сообщение «Заполните все поля» | Обязательные поля проверяет браузер; ошибки сервера показываются на странице | Проверка в самом браузере работает без запроса на сервер; сообщения сервера («Пользователь с таким email уже зарегистрирован») совпадают со сценарием |
| Вкладка «История квизов» и список «Вишлист» | Вкладки «История настроений» и «Хочу прочитать» | Названия приведены к функциональным требованиям («История книжных настроений», «Хочу прочитать»); слово «вишлист» заменено русским выражением |
| «Добавить комментарий» | Блок «Мои заметки», кнопка «Добавить заметку» | Такие записи видны только автору, поэтому название «заметки» точнее |
| Тест из вопросов | Тест подстраивается: на следующем шаге показываются только те ответы, для которых остались непрочитанные книги | Исключает тупики (жанр, которого нет в выбранном настроении) и выполняет требование «адаптивный тест» |
| Каталог до 1000 книг | Реальных книг около 50, остальные до 1000 создаются командой `seed_books.py --demo 1000` | Нужны для проверки скорости и нагрузки; в защите честно называть их демонстрационными |
| Подборка из 3-5 книг | Прочитанные исключаются; если подходящих мало, добираются наиболее близкие | Подборка всегда содержит не меньше трёх книг, пока в каталоге хватает непрочитанных |
